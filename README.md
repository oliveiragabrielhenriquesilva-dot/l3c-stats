# l3c-stats

Backoffice L3C Stats (Next.js)

Este repositório receberá o código do L3C Stats, Mesa de Estatísticas e hub de transmissão. **O servidor de produção não está conectado ao GitHub.**

Fluxo planejado: `feature/*` → validação → PR → homologação → publicação autorizada.

Exigir testes de sessão, permissões, cronômetro, operação offline/sincronização e integração GoChamps antes de qualquer atualização.

**Não enviar:** `.env` real, tokens, dados pessoais, bancos ou sessões.
